# dz brand, for the app

Use these so the app looks like dz from the first screen.

- Wordmark: lowercase **d&z**.
- Primary color: purple `#37246B`.
- Support color: bright blue `#3FB3E2`.
- Tagline: "every cart. every aisle."

Keep it clean and legible on a phone in a store aisle. Purple leads, blue supports, white space does the rest. No made-up logos or colors beyond these; if a real logo file is needed, get it from the dz brand kit rather than inventing one.
